# Invariant register — Session, metrics, and extension

[Invariant register](../invariants.md) · [Spice product model](../README.md)
## Session

| Label | Invariant |
| --- | --- |
| <a id="session-the-briefing-answers-four-questions-mechanically"></a>**The briefing answers four questions mechanically** | The briefing answers four questions mechanically: what was asked, what was last delivered, what the working set was, what steering is pending. |
| <a id="session-asks-are-sourced-from-the-steering-plane"></a>**Asks are sourced from steering and recovered compaction intent** | The steering plane and recovered compaction intent exclusively supply asks. Transcript prose contributes what happened and never supplies or backfills an ask. |
| <a id="session-recovery-shows-the-recovered-ask"></a>**Recovery shows the recovered ask** | Recovery shows the recovered ask rather than continuation boilerplate, and never renders assistant text as the user's ask. |
| <a id="session-a-briefing-requests-three-boundaries-and-a-sweep-normalizes-its-caller-count"></a>**A briefing requests three boundaries and a sweep normalizes its caller count** | A briefing always requests the newest three compaction boundaries. A syntactically valid nonpositive sweep count normalizes to one; any larger process-representable count is accepted without a Rust-side ceiling. |
| <a id="session-the-report-preserves-admitted-turn-and-dialogue-order"></a>**The report preserves admitted turn and dialogue order** | Selected turns retain canonical time/source order and their dialogue retains the decoder-admitted transcript order and text; the report layer adds no occurrence fold after decoder canonicalization. |
| <a id="session-windows-the-engine-could-not-read-are-reported-loudly"></a>**Windows the engine could not read are reported loudly** | Windows the engine could not read are reported loudly, not silently skipped. |
| <a id="session-message-shape-classification-is-deterministic-and-structural"></a>**Message-shape classification is deterministic and structural** | Message-shape classification is deterministic and structural, not a prefix sniff. |
| <a id="session-judge-and-maxim-scanning-exclude-generated-diff"></a>**Judge and maxim scanning exclude generated diff** | Judge and maxim scanning exclude generated diff, patch, and tool-output bodies. |
| <a id="session-at-most-one-maxim-reminder-per-content-derived-key-per-compaction-epoch"></a>**At most one maxim reminder per content-derived key per compaction epoch** | At most one maxim reminder per content-derived key per compaction epoch; self-echo suppressed. |
| <a id="session-a-confirmed-maxim-reminder-returns-as-ordinary-steering"></a>**A confirmed maxim reminder returns as ordinary steering** | A confirmed maxim reminder returns as ordinary steering; the counsel has no private channel. |
| <a id="session-adjudication-is-optional"></a>**Adjudication is optional** | With `judge.enabled` absent or false, a configured trigger hit publishes directly. When judging is enabled, equivalent framings are deterministically shuffled, then each is attempted sequentially through a fresh bounded judge child; absence, timeout, process error, or exhausted ambiguity abandons the candidate and emits nothing. |
| <a id="session-new-taste-is-mined-from-recurring-corrections-and-filed-as-a-proposal"></a>**New taste is mined from recurring corrections and filed as a proposal** | New taste is mined from recurring corrections and filed as a proposal, not invented. |
| <a id="session-the-transcript-supplies-what-happened"></a>**The transcript supplies what happened** | The transcript supplies what happened — deliveries, commits, commands, touched paths, boundaries. It never supplies what is being asked. |
| <a id="session-authoritative-pending-directives-use-their-recorded-publication-instants"></a>**Authoritative pending directives use their recorded publication instants** | Each pending directive is rendered with the publication instant in its authoritative steering head. An invalid steering-head read makes the steering probe unknown rather than dropping or restamping one directive. |
| <a id="session-a-directive-is-shown-only-for-the-thread-being-briefed"></a>**A directive is shown only for the thread being briefed** | A directive is shown only for the thread being briefed, and always carries the key needed to answer it. |
| <a id="session-the-briefing-declares-what-set-its-window"></a>**The briefing declares what set its window** | The briefing declares what set its window, where the window starts, and how many boundaries were requested versus selected — naming session start when no boundary exists. |
| <a id="session-recency-is-measured-against-the-newest-activity-actually-observed-in-the-material"></a>**Recency is measured against the newest activity actually observed in the material** | Recency is measured against the newest activity actually observed in the material, not against wall-clock now. |
| <a id="session-explicit-start-precedes-the-count-derived-horizon-and-end-filters-boundaries-first"></a>**Explicit start precedes the count-derived horizon and end filters boundaries first** | An explicit start replaces the count-derived horizon start. An explicit end filters candidate boundaries before the newest requested count is selected. |
| <a id="session-transcript-evidence-is-not-reranked-by-class-or-outcome"></a>**Transcript evidence is not reranked by class or outcome** | Selected turns retain canonical time/source order and dialogue retains admitted order; directive status and turn outcome do not create a second priority ranking. |
| <a id="session-only-the-actor-s-own-claim-is-enumerated"></a>**Only the actor's own claim is enumerated** | Only the actor's own claim is enumerated; peers' active work is reported as a count rather than as competing board rows. |
| <a id="session-only-the-two-optional-authority-arrays-omit-when-empty"></a>**Only the two optional authority arrays omit when empty** | `authorities.asks` and `authorities.unknowns` omit when empty. The Recall envelope — including sources, window, held work, pruning, residues, and their nested arrays — remains serialized. |
| <a id="session-turn-pruning-reports-thresholds-and-before-and-after-counts"></a>**Turn pruning reports thresholds and before-and-after counts** | The report carries the requested line and byte thresholds and selected-turn counts before and after pruning; the optional explanation is report metadata, not input to the estimate. |
| <a id="session-turn-pruning-removes-oldest-whole-turns-and-preserves-authority"></a>**Turn pruning removes oldest whole turns and preserves authority** | The line and byte estimates prune only the oldest whole transcript turns while more than one remains. Outstanding asks, held work, and report metadata are not pruned, and a lone over-threshold turn remains. |
| <a id="session-unavailable-authority-facts-remain-distinct-from-zero"></a>**Unavailable authority facts remain distinct from zero** | An unavailable authority value remains absent rather than becoming numeric zero, and its typed unknown names the authority, probe, and error detail. |
| <a id="session-discovery-and-rendering-share-one-deadline"></a>**Discovery and rendering share one deadline** | A briefing or sweep has one positive finite deadline covering source discovery through report construction. Recoverable authority-read errors become visible unknowns and construction continues; an invalid budget is refused, and exceeding a valid budget refuses with the action, requested or resolved inputs, and budget named but no partial report. |
| <a id="session-the-ambient-posture-priority-label-is-declarative-only"></a>**The ambient-posture priority label is declarative only** | Rust emits `ambient-posture` in the decision-priority metadata but produces no corresponding observation or section; the label is not evidence that a posture probe ran. |
| <a id="session-windows-tile-the-selected-horizon-contiguously"></a>**Windows tile the selected horizon contiguously** | Windows tile the selected horizon contiguously, so no matching activity inside it falls outside every window; a session that never compacted still yields exactly one window, respecting explicit bounds and labelled with why it has no internal boundaries. |
| <a id="session-an-exchange-straddling-a-boundary-belongs-to-both-adjacent-windows"></a>**An exchange straddling a boundary belongs to both adjacent windows** | An exchange straddling a boundary belongs to both adjacent windows, and only a compaction that actually severed context counts as a boundary. |
| <a id="session-material-read-only-to-establish-what-preceded-a-window-s-start-is-excluded-from-its-contents"></a>**Material read only to establish what preceded a window's start is excluded from its contents** | Material read only to establish what preceded a window's start is excluded from its contents, so a window holds the same records however much surrounding material was consulted. |
| <a id="session-boundary-discovery-follows-the-source-compression-profile"></a>**Boundary discovery follows the source compression profile** | An uncompressed seekable transcript is scanned backward and stops after enough boundaries; an admitted gzip transcript is scanned forward and retains the newest requested markers. |
| <a id="session-the-unit-of-the-record-is-one-operator-ask"></a>**The unit of the record is one operator ask** | The unit of the record is one operator ask; every observed activity is attributed to the ask open when it occurred, and activity before any ask opens a record of its own. |
| <a id="session-an-exchange-is-complete-only-when-the-transcript-says-it-ended"></a>**An exchange is complete only when the transcript says it ended** | An exchange is complete only when the transcript says it ended; otherwise it stays open, its extent taken from its last observed activity, and a window holding one is itself open. |
| <a id="session-records-merged-from-several-transcripts-order-by-time-with-source-identity-breaking-ties"></a>**Records merged from several transcripts order by time with source identity breaking ties** | Records merged from several transcripts order by time with source identity breaking ties, and the differing timestamp spellings of different vendors compare as the same instant. |
| <a id="session-recorded-text-is-exactly-what-the-transcript-held"></a>**Recorded text is exactly what the transcript held** | Recorded text is exactly what the transcript held; only explicitly derived fields are reformatted, and a display echo is not a second occurrence. |
| <a id="session-a-fact-whose-classification-disagrees-with-the-evidence-backing-it-aborts-the-projection"></a>**A fact whose classification disagrees with the evidence backing it aborts the projection** | A fact whose classification disagrees with the evidence backing it aborts the projection rather than producing a degraded record. |
| <a id="session-an-invocation-and-its-outcome-are-separate-facts"></a>**An invocation and its outcome are separate facts** | An invocation and its outcome are separate facts: a command whose outcome was never observed is neither successful nor failed, and an outcome attaches to the invocation it names. |
| <a id="session-turn-id-filtering-is-refused-only-when-the-dataset-lacks-turn-identities"></a>**Turn-ID filtering is refused only when the dataset lacks turn identities** | Requesting `--turn-id` against a nonempty dataset whose turns uniformly lack identities is capability-refused with temporal and content alternatives named. Ordinary nonmatching filters produce an empty selection. |
| <a id="session-explicit-subjects-resolve-in-caller-order-and-paths-deduplicate"></a>**Explicit subjects resolve in caller order and paths deduplicate** | Explicit subjects resolve in caller order and the first failing input refuses the request. Successfully resolved canonical paths contribute once even when named repeatedly. |
| <a id="session-an-unnamed-subject-prefers-live-vendor-identity-then-current-directory-transcripts"></a>**An unnamed subject prefers live vendor identity, then current-directory transcripts** | With no subject, resolution uses the first captured live vendor identity when present; otherwise it admits every sorted `.jsonl` and `.jsonl.gz` in the current directory and refuses only when no source resolves. |
| <a id="session-an-agent-identity-is-current-only-while-present-in-the-running-environment"></a>**An agent identity is current only while present in the running environment** | An agent identity counts as current only while it is present in the running process's environment, never when it is merely persisted in the tree from an earlier session. |
| <a id="session-the-meter-announces-a-state-key-change-or-a-due-lease-reminder"></a>**The meter announces a state-key change or a due lease reminder** | What was last shown survives process exit. The meter speaks when its state key changes or the current lease tier's reminder cadence is due; before that cadence, identical state remains silent. A missing or unusable record makes it speak. |
| <a id="session-the-lease-reminder-cadence-narrows-as-expiry-approaches"></a>**The lease reminder cadence narrows as expiry approaches** | Claim state is the only working-state signal repeated on a timer, and the tier-specific reminder cadence narrows as expiry approaches. |
| <a id="session-failing-to-collect-the-meter-s-working-state-degrades-to-silence"></a>**Failing to collect the meter's working state degrades to silence** | Failing to collect the meter's working state degrades to silence and never changes the outcome of the command being decorated. |
| <a id="session-a-nonempty-typed-record-with-an-invalid-timestamp-is-refused"></a>**A nonempty typed record with an invalid timestamp is refused** | The session dataset refuses any nonempty typed record whose timestamp cannot normalize with `session::transcript-timestamp-invalid`; it neither drops nor restamps the record. |
| <a id="session-an-unknown-context-window-stays-unknown"></a>**An unknown context window stays unknown** | An unknown model context window stays unknown rather than defaulting to a nominal size. |
| <a id="session-a-reporting-window-with-no-surviving-source-is-marked-incomplete"></a>**A reporting window with no surviving source is marked incomplete** | A reporting window with no surviving source is marked incomplete rather than reported as zero effort. |
| <a id="session-a-phase-boundary-requires-a-long-idle-gap-or-an-activity-change-that-persists-on-both"></a>**A phase boundary requires a long idle gap or an activity change that persists on both** | A phase boundary requires a long idle gap or an activity change that persists on both sides of it, so a single deviating turn never starts a phase. |
| <a id="session-a-maxim-bag-is-one-opinion-with-several-triggers"></a>**A maxim bag is one opinion with several triggers** | A maxim bag is one opinion with several triggers. Matching is over whole words with no stemming, so a bag enumerates its own variations and the matcher never mutates prose to find a hit. |
| <a id="session-a-trigger-must-be-an-alphabetic-word-or-phrase-and-is-refused-at-load-otherwise"></a>**A trigger must be an alphabetic word or phrase and is refused at load otherwise** | A trigger must be an alphabetic word or phrase and is refused at load otherwise; a trigger that can never match a word is a silently dead opinion. |
| <a id="session-one-statement-fires-a-bag-at-most-once-however-many-of-its-triggers-hit"></a>**One statement fires a bag at most once however many of its triggers hit** | Within one match, a statement selects a bag at most once however many triggers hit, and candidates order by declared bag order then trigger. The same prose produces the same candidate sequence; repeating its content-derived key within one compaction epoch emits no second reminder. |
| <a id="session-bag-applicability-uses-the-one-shared-selector-grammar"></a>**Bag applicability uses the one shared selector grammar** | Bag applicability uses the one shared selector grammar, and a bag is disabled by name in a tracked record, so every clone sees the same opinions in force and every disablement is enumerable. |
| <a id="session-adjudication-states-the-question-in-several-equivalent-framings-and-shuffles-them"></a>**Adjudication states the question in several equivalent framings and shuffles them** | Adjudication deterministically shuffles equivalent framings from the content-derived evidence key. The same evidence repeats the same order and different evidence may produce a different order; a reply that does not collapse to yes or no is retried a bounded number of times and then abandoned rather than interpreted. |

## Metrics

| Label | Invariant |
| --- | --- |
| <a id="metrics-transcript-accounting-retains-typed-usage-and-record-counts"></a>**Transcript accounting retains typed usage and record counts** | Each normalized usage sample retains its exact ordered byte spans and event ordinal. Complete records carrying no usage and residue records remain separate counts rather than invented activity facts. |
| <a id="metrics-a-source-head-is-generation-and-position-not-an-offset"></a>**A source head is generation and position, not an offset** | Resumption requires the exact source generation and next member/offset position. A replacement restarts at member 1, offset 0 and explicitly names the superseded generation. |
| <a id="metrics-an-accounted-batch-and-its-advanced-source-head-commit-together"></a>**An accounted batch and its advanced source head commit together** | One guarded journal transaction commits the accounted batch and its advanced source head together; failure leaves neither, and discontinuity refuses both. |
| <a id="metrics-effort-segments-retain-exact-source-and-attribution"></a>**Effort segments retain exact source and attribution** | A claim-to-terminal phase records its opening and closing facts and boundaries, while every verified source-contiguous segment retains lane, occupant, lineage, session, source positions, launch identity, and usage. |
| <a id="metrics-unavailable-effort-is-reason-coded-and-excluded-from-aggregates"></a>**Unavailable effort is reason-coded and excluded from aggregates** | A partial, interrupted, discontinuous, unattributable, malformed, untagged, mixed-identity, or overflowing phase remains visible with stable reasons and contributes to no numeric aggregate. |
| <a id="metrics-effort-aggregates-partition-by-launch-identity-and-phase"></a>**Effort aggregates partition by launch identity and phase** | Numeric totals and integer averages partition by exact vendor, model, reasoning effort, and workflow phase. |
| <a id="metrics-canvas-metrics-render-current-member-standing"></a>**Canvas Metrics render current member standing** | For every member of the selected team, Canvas Metrics render pending count, claim age, renewal age, and liveness. The mode badge counts members holding claims. |

## Extension, wire, and configuration

| Label | Invariant |
| --- | --- |
| <a id="extension-one-wire-vocabulary-is-compiled-through-every-producer-and-consumer"></a>**One wire vocabulary is compiled through every producer and consumer** | Shared Rust wire types are the single vocabulary compiled into resident producers and application consumers. Duplicate hand-maintained schemas cannot drift; an incompatible change fails compilation or the selected compatibility gate. |
| <a id="extension-payloads-are-validated-at-their-emitters"></a>**Payloads are validated at their emitters** | Payloads are validated at their emitters, not only at their readers. |
| <a id="extension-an-answer-with-two-shapes-is-two-types"></a>**An answer with two shapes is two types** | An answer with two shapes is two types, discriminated on meaning, so a reader cannot take a field off the arm that never carried it. |
| <a id="extension-a-field-one-arm-never-carries-is-declared-absent"></a>**A field one arm never carries is declared absent** | A field one arm never carries is declared absent so the reader may narrow on it. |
| <a id="extension-absence-has-one-spelling-enforced-mechanically"></a>**Absence has one spelling, enforced mechanically** | Absence has one spelling, enforced mechanically. |
| <a id="extension-built-in-verbs-and-registered-actions-win-at-every-depth"></a>**Built-in verbs and registered actions win at every depth** | Built-in verbs and registered actions win at every depth; a shadowing mount fails loudly. |
| <a id="extension-a-new-vendor-wrapper-or-gate-is-a-declared-value"></a>**A new vendor, wrapper, or gate is a declared value** | A new vendor, wrapper, or gate is a declared value, not a patch to a dispatcher. |
| <a id="extension-vendor-resolution-is-explicit"></a>**Vendor resolution is explicit** | Vendor resolution is explicit: environment, then configured vendor, then a default for unbound worktrees. |
| <a id="extension-every-effective-configuration-value-carries-its-source-provenance"></a>**Every effective configuration value carries its source provenance** | Every effective configuration value carries its source provenance. |
| <a id="extension-bad-configuration-fails-loudly"></a>**Bad configuration fails loudly** | Bad configuration fails loudly. |
| <a id="extension-gate-policy-study-and-taste-maxim-applicability-share-one-selector-grammar"></a>**Gate policy/study and taste/maxim applicability share one selector grammar** | Gate policies and studies and tastes and maxims share the exact path, extension, vendor, model, and phase selector grammar. Shell wrappers do not use it, and configured pre-commit command scopes are a separate path-only contract. |
| <a id="extension-the-command-optimizer-is-optional"></a>**The command optimizer is optional** | The command optimizer is optional; an unusable one degrades to native execution and reports health without blocking. |
