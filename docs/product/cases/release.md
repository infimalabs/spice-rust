## Cases
### Release as a plan

| Situation | Expected | Ref |
| --- | --- | --- |
| A release publication verb is invoked without execution authorization | the complete ordered plan renders; nothing is committed, tagged, pushed, or published | [Release publication renders its complete ordered plan](../invariants/distribution.md#distribution-release-publication-renders-its-complete-ordered-plan) |
| A plan is read, an input moves, then execution is requested with the prior digest | refused, naming the fresh expected plan identity and the supplied prior identity | [An execution request pins the digest of the plan that was read](../invariants/distribution.md#distribution-an-execution-request-pins-the-digest-of-the-plan-that-was-read) |
| The notes file is edited between preview and execution | the pinned digest no longer matches; refused | [Plan identity covers every input to publication](../invariants/distribution.md#distribution-plan-identity-covers-every-input-to-publication) |
| The target commit is moved between preview and execution | the pinned digest no longer matches; refused | [Plan identity covers every input to publication](../invariants/distribution.md#distribution-plan-identity-covers-every-input-to-publication) |
| A plan is rendered | the publication steps appear in the order they will run | [Step order is part of what the plan commits to](../invariants/distribution.md#distribution-step-order-is-part-of-what-the-plan-commits-to) |
| The named notes file does not exist | refused while the plan is built, before any gate runs | [Preconditions that can be evaluated without effect are evaluated](../invariants/distribution.md#distribution-preconditions-that-can-be-evaluated-without-effect-are-evaluated) |
| Publish starts at the clean source commit carrying the source version | admitted as fresh local release progress | [Local release progress admits only three exact shapes](../invariants/distribution.md#distribution-local-release-progress-admits-only-three-exact-shapes) |
| Publish resumes at the source commit with only `dist/VERSION` changed exactly to the requested version | admitted as the sole version-only intermediate; any other tracked change refuses | [Local release progress admits only three exact shapes](../invariants/distribution.md#distribution-local-release-progress-admits-only-three-exact-shapes) |
| Publish resumes at the clean deterministic release commit | admitted; a different local commit or version refuses | [Local release progress admits only three exact shapes](../invariants/distribution.md#distribution-local-release-progress-admits-only-three-exact-shapes) |
| Tag-and-announce starts anywhere except the clean deterministic release commit at HEAD | refused | [Local release progress admits only three exact shapes](../invariants/distribution.md#distribution-local-release-progress-admits-only-three-exact-shapes) |

### Release gates and evidence

| Situation | Expected | Ref |
| --- | --- | --- |
| Any arm in the canonical strict correctness battery fails for a fresh publish of the plan's source commit | the bump and every external publication effect remain unattempted | [The release gate runs the complete strict battery over one immutable source](../invariants/distribution.md#distribution-the-release-gate-runs-the-complete-strict-battery-over-one-immutable-source) |
| The version bump produces a version other than the accepted plan requested | fresh publish aborts before its deterministic release commit is created or published | [The version the bump produces must equal the version the plan named](../invariants/distribution.md#distribution-the-version-the-bump-produces-must-equal-the-version-the-plan-named) |
| The target payloads disagree with the source carried by their manifest | refused while the package is admitted | [Targets bind the manifest source while plan source is separately admitted](../invariants/distribution.md#distribution-targets-bind-the-manifest-source-while-plan-source-is-separately-admitted) |
| The manifest source digest differs from the publication plan's source commit | both identities remain separately admitted; the current profile performs no equality check between them | [Targets bind the manifest source while plan source is separately admitted](../invariants/distribution.md#distribution-targets-bind-the-manifest-source-while-plan-source-is-separately-admitted) |
| Project metadata or tracked checkout status moves between preview and execution | the freshly derived plan or admitted local-state identity moves; execution refuses before committing | [An execution request pins the digest of the plan that was read](../invariants/distribution.md#distribution-an-execution-request-pins-the-digest-of-the-plan-that-was-read) |
| Tag-and-announce names an existing release commit whose bump subject, deterministic fold, or live release version disagrees with the requested version | refused | [Tag-and-announce admits the requested deterministic release identity](../invariants/distribution.md#distribution-tag-and-announce-admits-the-requested-deterministic-release-identity) |
| The version's tag already exists on a different commit | refused; the tag is not moved | [A version names exactly one commit](../invariants/distribution.md#distribution-a-version-names-exactly-one-commit) |
| Checkout HEAD or tracked source moves, or an untracked path appears outside `dist/stage/objects/` and `dist/stage/targets/`, while one target is being staged | target staging refuses before publishing its payload pointer; untracked entries beneath those two exact release-output roots remain admitted | [Target staging captures and guards the current checkout commit](../invariants/distribution.md#distribution-target-staging-captures-and-guards-the-current-checkout-commit) |
| The two native targets are prepared in canonical order | `aarch64-apple-darwin`, then `x86_64-unknown-linux-musl`; each binds its own payload, and package admission requires both payloads to match the manifest source | [The target matrix is exact and ordered](../invariants/distribution.md#distribution-the-target-matrix-is-exact-and-ordered) |
| A target is missing, duplicated, extra, or reordered | refused before effect planning | [The target matrix is exact and ordered](../invariants/distribution.md#distribution-the-target-matrix-is-exact-and-ordered) |
| Proof runs for a payload whose source digest does not name the current candidate checkout | replay still uses the current checkout; proof itself performs no workspace-to-payload source comparison | [Proof replays the current candidate checkout](../invariants/distribution.md#distribution-proof-replays-the-current-candidate-checkout) |
| A staged target executable byte changes after proof | proof does not inspect that executable; later package materialization recomputes the executable digest and refuses disagreement with the payload inventory | [The artifact gate rechecks output from a persistent release target](../invariants/distribution.md#distribution-the-artifact-gate-rechecks-output-from-a-persistent-release-target) |
| A proof replay is non-clean | refused with no detached receipt published | [Only clean proof publishes and admits a detached receipt](../invariants/distribution.md#distribution-only-clean-proof-publishes-and-admits-a-detached-receipt) |
| A proof receipt is malformed, names another target, or carries an unverifiable digest | refused before sealing | [Only clean proof publishes and admits a detached receipt](../invariants/distribution.md#distribution-only-clean-proof-publishes-and-admits-a-detached-receipt) |
| One required target has no accepted receipt | the post-proof seal refuses; partial target coverage is never a release | [Sealing occurs after proof](../invariants/distribution.md#distribution-sealing-occurs-after-proof) |
| Any artifact or receipt changes after sealing | its digest no longer matches the immutable release identity | [Sealing occurs after proof](../invariants/distribution.md#distribution-sealing-occurs-after-proof) |
| Build output from an earlier run remains in the release target directory | the target directory may be reused; package materialization must still reproduce the exact planned package and Git-tree identities | [The artifact gate rechecks output from a persistent release target](../invariants/distribution.md#distribution-the-artifact-gate-rechecks-output-from-a-persistent-release-target) |
| The compiled-host staged path is a readable symlink or lacks executable mode | its bytes may still be admitted, copied to a regular probe file, and chmodded there; the copied process must exit successfully | [The artifact gate rechecks output from a persistent release target](../invariants/distribution.md#distribution-the-artifact-gate-rechecks-output-from-a-persistent-release-target) |
| The copied executable exits successfully but prints an unexpected version document | the current probe accepts process success; it does not decode stdout as a version identity | [The artifact gate rechecks output from a persistent release target](../invariants/distribution.md#distribution-the-artifact-gate-rechecks-output-from-a-persistent-release-target) |

### Release notes

| Situation | Expected | Ref |
| --- | --- | --- |
| A merged branch carries many internal commits | one entry, not one per commit | [First-parent landings produce single entries](../invariants/distribution.md#distribution-first-parent-landings-produce-single-entries) |
| One task first lands under project A and later lands under project B | one entry at the task's first sequence position, with the latest subject, grouped under project B | [Landings sharing a task identity collapse into one entry](../invariants/distribution.md#distribution-landings-sharing-a-task-identity-collapse-into-one-entry) |
| A revert names a commit that only exists on a side branch | paired with the landing whose history contains it; both suppressed | [A revert pairs with the landing whose history contains the reverted commit](../invariants/distribution.md#distribution-a-revert-pairs-with-the-landing-whose-history-contains-the-reverted-commit) |
| Two landings in one project bucket produce the same edited description | merged, and every contributing reference survives | [Note rendering preserves references and project-bucket order](../invariants/distribution.md#distribution-note-rendering-preserves-references-and-project-bucket-order) |
| Two landings in different project buckets produce the same edited description | remain separate entries in their respective buckets | [Note rendering preserves references and project-bucket order](../invariants/distribution.md#distribution-note-rendering-preserves-references-and-project-bucket-order) |
| Collapsed note entries from interleaved projects are rendered | project buckets appear in first-seen order within the collapsed entry sequence and preserve entry order within each bucket; no global landing order or raw-history project order is promised across buckets | [Note rendering preserves references and project-bucket order](../invariants/distribution.md#distribution-note-rendering-preserves-references-and-project-bucket-order) |
| A commit touches paths belonging to several areas and declares a non-agent project | grouped by that declared project, not inferred from its paths | [Note project buckets follow declarations with one general collapse](../invariants/distribution.md#distribution-note-project-buckets-follow-declarations-with-one-general-collapse) |
| A commit declares no project | lands in the `general` grouping rather than disappearing | [Note project buckets follow declarations with one general collapse](../invariants/distribution.md#distribution-note-project-buckets-follow-declarations-with-one-general-collapse) |
| A commit declares an `agent.*` project | lands in the `general` grouping; it does not create a separate agent-project bucket | [Note project buckets follow declarations with one general collapse](../invariants/distribution.md#distribution-note-project-buckets-follow-declarations-with-one-general-collapse) |
| A description merely ends in a hyphenated token | left intact; stripping requires a match against that commit's own identifier | [A trailing handle is stripped from a description only when it matches that commit's own recorded](../invariants/distribution.md#distribution-a-trailing-handle-is-stripped-from-a-description-only-when-it-matches-that-commit-s-own-recorded) |
| A branch shares a name with a release tag | the range resolves through the tag's own ref namespace | [The window runs from the highest-versioned prior release tag reachable from the release commit](../invariants/distribution.md#distribution-the-window-runs-from-the-highest-versioned-prior-release-tag-reachable-from-the-release-commit) |
| A prior tag exists but is not reachable from the release commit | not chosen as the window's start | [The window runs from the highest-versioned prior release tag reachable from the release commit](../invariants/distribution.md#distribution-the-window-runs-from-the-highest-versioned-prior-release-tag-reachable-from-the-release-commit) |
| No prior release tag exists | a bounded window of recent landings, and the output says so | [The window runs from the highest-versioned prior release tag reachable from the release commit](../invariants/distribution.md#distribution-the-window-runs-from-the-highest-versioned-prior-release-tag-reachable-from-the-release-commit) |
| Notes are published | the curated region is kept; the inventory is regenerated against the real release commit | [Curation owns the region above the generated inventory](../invariants/distribution.md#distribution-curation-owns-the-region-above-the-generated-inventory) |
| Notes are the untouched generated draft | refused | [Notes are refused when they are an untouched draft](../invariants/distribution.md#distribution-notes-are-refused-when-they-are-an-untouched-draft) |
| Notes still carry the highlights placeholder | refused | [Notes are refused when they are an untouched draft](../invariants/distribution.md#distribution-notes-are-refused-when-they-are-an-untouched-draft) |
| The curated region holds only banner text and headings | refused | [Notes are refused when they are an untouched draft](../invariants/distribution.md#distribution-notes-are-refused-when-they-are-an-untouched-draft) |

### Publication

| Situation | Expected | Ref |
| --- | --- | --- |
| The publishing credential is missing or malformed | refused before the push, not after | [Credentials are obtained and validated before the first externally visible action](../invariants/distribution.md#distribution-credentials-are-obtained-and-validated-before-the-first-externally-visible-action) |
| Source transport or guarded package-ref publication would be rejected | found by its explicit no-effect rehearsal before the corresponding publication | [Only source and package publication have explicit rehearsal steps](../invariants/distribution.md#distribution-only-source-and-package-publication-have-explicit-rehearsal-steps) |
| Tag or announcement publication is next | executed directly as a convergent Git mutation; the plan contains neither a rehearsal nor an unrehearsable marker for it | [Only source and package publication have explicit rehearsal steps](../invariants/distribution.md#distribution-only-source-and-package-publication-have-explicit-rehearsal-steps) |
| A release publishes | payloads and receipts remain bound through manifest and package, while tag and announcement name the plan's release commit; no manifest-source-to-plan-source equality is implied | [Publication carries sealed and plan identities without equating their sources](../invariants/distribution.md#distribution-publication-carries-sealed-and-plan-identities-without-equating-their-sources) |
| A required visibility observation never arrives | the run fails loudly; dependent tag and announcement steps do not proceed | [Publication carries sealed and plan identities without equating their sources](../invariants/distribution.md#distribution-publication-carries-sealed-and-plan-identities-without-equating-their-sources) |
| A release is interrupted after the source ref publishes but before the one sealed package upload, then re-run | each external operation converges without duplicating the sealed object | [Every publication step converges](../invariants/distribution.md#distribution-every-publication-step-converges) |
| The operator interrupts a release | terminates with a status distinct from a gate failure | [An operator interruption terminates with a status distinct from a gate failure](../invariants/distribution.md#distribution-an-operator-interruption-terminates-with-a-status-distinct-from-a-gate-failure) |
