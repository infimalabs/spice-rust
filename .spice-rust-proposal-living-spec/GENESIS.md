# Raise spice whole from genesis

Acceptance: The daemonless verbs watch, retro, gate, and proof answer from one binary with no resident and with their declared network posture
Acceptance: One journal transaction commits every command id, fact, authoritative task and workflow head update, coordination head update, and result
Acceptance: One foreground resident holds the kernel writer lock before opening authority and no live takeover path exists
Acceptance: Both release targets pass their sealed proof and bind their binary, embedded app, toolchain, container, and detached proof receipt into the one sealed release manifest
Flow: verify, review
Priority: high
Project: spice.genesis
Origin: repo:genesis
Tags: genesis, trunk

spice is raised as one Rust appliance around two forms of truth. Vendor bytes
record what happened; the authoritative task, workflow, and coordination heads
record what is wanted now. Immutable facts explain every transition, while
folds remain disposable answers that authority never reads.

The resident is the single writer and the command door. It derives principals
from connection capabilities, checks subject witnesses, and commits each
command atomically in the journal. The journal is the only authority; Git,
tape, files, and release targets are external evidence and artifact
boundaries, so each crossing uses a named recoverable plan rather than a
claim of false atomicity.

The entry ladder stays honest. watch and retro are daemonless and offline;
gate is daemonless and toolful; proof is daemonless with its container and
network posture named. steer and fleet require `spice up`, whose foreground
process holds the kernel lock and owns the journal commit capability.

Evidence precedes every surface that cites it. Raw vendor bytes become
durable before interpretation, every shortened list uses `Packed`, every wait
has a real wake and a bound, and every withdrawn surface refuses while naming
its owning release and remedy. Trust is granted through the quarantine boot
before any workspace-controlled surface executes. Python spice remains the
scaffold authority until the measured Rust slice, full gate frame, and
enforcement flip are proved.

This program is worked, not swallowed. One agent starts alone: build in wave
order, mint a leaf into a live task when it becomes current, and let the
board grow with the work rather than ahead of it. Acceptance lines define
done for the work they describe whether or not a leaf ever became a board
row. When construction teaches something these documents do not know, amend
the corpus first — FRAME records the decision, the references follow in the
same change, and the affected leaves here are rewritten before they are
taken.

> Two processes racing a naive read-check-write claim both won; one journal transaction must make that outcome unrepresentable.
> A library task commit measured about 4ms while a process invocation cost about 40ms; the clean break removes the process seam rather than preserving it.
> An old gate distribution piled up at its elastic limit while a large forwarding routine scored as trivial; outcome floors and mutation kills replace threshold theater.
> The executable wire generated 116 browser definitions without a version field; wire v1 and current-only hello close that hole.
> Roughly 6k lines of tests asserted on script and style text, including hundreds of absence assertions; behavioral Rust fixtures remove that surface.
> Vendor field renames silently removed reasoning display and zeroed context meters; verbatim tape, residue, absence states, and canaries make drift visible.
> Two dozen checks ran only on the committing machine; sealed proof and target manifests move evidence to the release boundary.
